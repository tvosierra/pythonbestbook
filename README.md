# AMAZON BESTSELLING BOOKS
El objetivo de este ejercicio es poner en practica conocimientos sobre el uso del lenguaje PYTHON y la libreria PANDAS.

## Este proyecto analiza un conjunto de datos utilizando Python y Pandas para obtener estadísticas descriptivas y visualizar información relevante.

En este ejercicio, trabajaremos con un archivo CSV (valores separados por comas) que contiene datos interesantes sobre los 550 libros más vendidos en Amazon entre 2009 y 2019 (proporcionados por Kaggle).

## Librerias utilizadas
* Python
* Pandas

## Uso 
1. Descarga el dataset desde la web kaggle (Amazon Top 50 Bestselling Books 2009 - 2019)
3. El nombre del archivo debe ser el tuyo, el mio es bestsellersAmazon.csv
4. Establecer ruta local o remota de tus archivos en la variable my_path_file, se recomienda que sea la misma ruta de tu proyecto.
5. Ejecutar archivo principal 
    python main.py
